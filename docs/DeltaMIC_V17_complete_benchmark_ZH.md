# ΔMIC预测完整基准测试结果：V17

报告日期：2026-10-28。正式主基准包括TIGER-pair、TIGER-single和21种外部预测器，共23个模型骨干。每个骨干各有含负样本和无负样本两种训练方案，每方案10种子（120–129），合计460个种子级结果；TIGER-ensemble另列。TIGER-pair采用Unsigned quota 20,000的V17主模型；TIGER-single采用已同步至基准的single-peptide head结果。

## 评价对象与指标

外测集含208条肽、11个家族、2,211个定向家族内配对。标签为ΔMIC = log₂ MIC（锚肽）−log₂ MIC（查询肽）；正值表示查询肽活性更强。每个种子先在各家族内计算指标，再对11个家族等权平均。表内均为10个种子家族宏指标的均值±样本标准差。

PCC为家族宏平均Pearson r；KCC为家族宏平均Kendall τb，两者越高越好。log10MAE为配对预测误差转换至log₁₀单位后的平均绝对误差：mean(|预测log₂差值−真实log₂差值|)×log₁₀2。RSE为家族内残差平方和除以真实差值相对该家族均值的总平方和；log10MAE和RSE越低越好。
