# Third-party code and data notices

This review package includes project-specific training/evaluation adaptations and source snapshots from the original method implementations. Original citations are listed in `docs/methods_benchmark_EN.md` and `docs/methods_benchmark_ZH.md`. Peptide-source DOIs are retained in `data/external_peptides.csv` and the training metadata.

Available upstream LICENSE, COPYING and NOTICE files are preserved alongside architecture sources under `code/archive/architecture_dependencies/`. `provenance/third_party_inventory.csv` lists the packaged source directories, available license files and locally recorded upstream repository URLs when available.

A license in a third-party subdirectory applies to that component under its own terms. No repository-wide replacement license is assigned here. Where no upstream license is present, this package does not assert a new redistribution or reuse permission. Project-specific code and data retain their existing authorship and rights; no new open-source license has been invented during packaging.

No trained or pretrained model weights, serialized estimators, embedding caches, graph caches, credentials or private keys are intended for inclusion. Font files are not redistributed. Source code may name external checkpoints and retain their hashes for provenance; those references are not checkpoint contents.
